# 条码扫码计数工具

一款简洁实用的微信小程序，适用于条码统计、表格导出、活动签到等需要快速扫码计数的场景。

## 功能特点

- **扫码计数** — 调起微信原生扫码能力，一秒即可完成一次扫码计数
- **两种模式** — 单次模式（弹窗输入数量）/ 连续模式（自动计 1）
- **本地存储** — 所有数据保存在手机本地，无需联网，保护隐私
- **数据管理** — 支持编辑数量、删除记录、导出 CSV 文件
- **震动反馈** — 扫码成功时提供触觉反馈，体验更直观
- **主题绿色** — 使用品牌绿色 `#5CB85C`，视觉统一](# 主题绿色** — 使用微信绿色规范色 `#07C160`，视觉统一）

## 使用流程

1. 打开小程序，点击「新建任务」
2. 输入任务名称（可选，默认使用时间）
3. 对准条码开始扫码
4. 扫码成功后震动提示，自动记录
5. 完成后查看详情，可导出 CSV 文件

## 技术栈

- 微信小程序原生框架（WXML + WXSS + JS）
- 本地存储 `wx.setStorageSync` / `wx.getStorageSync`
- Camera 组件 `scan-code` 模式

## 常见问题

**Q：扫码无反应？**
A：请在手机上真机调试，模拟器不支持 camera 扫码。

**Q：数据会丢失吗？**
A：数据保存在手机本地缓存，卸载小程序或清除缓存会丢失数据，建议重要数据及时导出 CSV 备份。

**Q：支持哪些条码格式？**
A：取决于微信 Camera 组件的 `scan-code` 能力，通常支持 EAN-13、EAN-8、CODE-128、CODE-39、ITF 等主流格式。
